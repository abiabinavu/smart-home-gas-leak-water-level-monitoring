# Smart Home Monitoring: Gas Leakage and Water-Level Detection

A microcontroller-based home monitoring project that combines gas-leak and water-level sensing to identify unsafe conditions and trigger alerts.

## Project overview

The system monitors the home environment using sensor inputs. Threshold-based logic is used to detect gas leakage or an unsafe water level and generate an alert for the user.

## Technical focus

- Microcontroller-based monitoring
- Gas-leak and water-level sensors
- Sensor interfacing
- Threshold logic and alert handling
- Real-time monitoring
